# Возможности ArenaMW

## Standalone-архитектура
ArenaMW работает только с локальным состоянием OpenMW. TES3MP-клиент, выделенный сервер, браузер серверов, RakNet-пакеты и серверная Lua-authority не нужны и в runtime ArenaMW не входят.

## Прокачка и механики
- Нативная XP-прокачка, кривая уровней, очки навыков, масштабирование сложности и потеря части незакреплённого XP после смерти.
- Требования оружия/брони, переработка боя, экономики, обучения, скрытности и торговли.
- Refined-Alchemy-подобная алхимия: знания ингредиентов, правила зелий и заряды яда на оружии.
- Локальное автоматическое воскрешение у подходящего святилища.

## AI и взаимодействия
- Тактический combat AI, выбор сильнейшей атаки, приоритет лечения, улучшения pathing/collision.
- Преследование через двери и локальное восстановление маршрута там, где это допускает модель мира OpenMW 0.47.
- Динамические idle/walk-анимации, постоянные позы и анимированные взаимодействия с предметами/контейнерами/книгами.

## Интерфейс
- Кинематографический Arena Dialogue со встроенным убеждением и клавиатурной навигацией.
- Arena HUD, информация о цели, боевые полоски, время, QuickLoot и переработанное создание персонажа.
- Встроенная EN/RU локализация Arena-интерфейса.
- Отдельный HUD FPS; F3/F4 остаются HDR/Bloom.

## Рендер
- HDR, Bloom, SMAA/native post-process.
- PBR-совместимые материалы/освещение и пресеты качества.
- Опциональный Project Magnus Clustered Lighting для desktop OpenGL 4.3; при отсутствии поддержки используется fallback на shader-compatible lighting.
- Simple и New/PBR water, отражения, преломление, ripples и полный набор ручных Water-настроек в лаунчере.
- Динамические тени со связью дальности теней и viewing distance.
- CPU masked occlusion culling для terrain/statics.
- Y001s/X040: выбранная в лаунчере OSG threading model реально применяется к viewer, CharacterPreview освобождается безопасно для render thread.

## Лаунчер
- Hardware detection и Auto/Minimum/Low/Balanced/Medium/High/Ultra.
- Y001s merge-safe сохранение ручных графических параметров.
- Portable `build.ini`: build name, data path, language, content/groundcover/BSA order. Сетевые address/port поля игнорируются.
- Сохранены Wizard и INI importer.

## Экспериментальные части
Ragdoll, часть продвинутого рендера и Android/gl4es пока считаются экспериментальными. Для Y001s основная проверяемая release-цель — Windows x64.
