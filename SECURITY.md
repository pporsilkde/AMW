# Security policy

Security and stability fixes target the latest ArenaMW source snapshot.

For reports, include the ArenaMW revision, OS, compiler/build type, CPU/GPU/driver, exact reproduction steps and relevant logs. Review crash dumps before public upload because they may contain local paths or user names.

Do not publish credentials, private data or working exploits. ArenaMW has no dedicated multiplayer server in this repository; network-security guidance from ArenaMP does not apply to the standalone runtime.
