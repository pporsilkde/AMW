# X016 — проверка поведения боевых полосок X014

Проверено по коду: `apps/openmw/mwgui/hud.cpp`, `hud.hpp`, `apps/openmw/mwworld/worldimp.cpp`,
`apps/openmw/mwmechanics/actors.cpp`, `apps/openmw/mwbase/*`.

## Совпадает с заявленным

| Пункт | Где реализовано |
|---|---|
| Полоска у того, кто в AiCombat с игроком | `Actors::getActorsFighting` → `isInCombat(actor)` |
| Не зависит от `fNPCHealthBarTime` | `setEnemy` больше не показывает старую полосу |
| В бою нет имени/уровня/цифр | `updateFocusedTargetPanel` гасит панель для участника боя |
| Союзник в бою получает полоску | `getActorsSidingWith` + `isInCombat()` |
| 118×9 → 47×4 | `minimumScale 0.40`: 118·0.4=47.2→47, 9·0.4=3.6→4 |
| Fade ~3200 → 4096 | `fadeStartDistance = 4096·0.78 = 3194.9` |
| До 24 участников | `combatHealthBarPoolSize = 24` |
| Пересчёт 10 Гц, позиция/HP каждый кадр | `mCombatHealthBarScanTimer = 0.10f` |
| Старая полоса врага в HUD убрана | `mEnemyHealth` переиспользован под hover-панель |
| Мирный NPC сохраняет панель имя+уровень+HP | `updateEnemyHealthBar`, ветка `usingFocusActor` |

## Не совпадало — исправлено

**1. Цвет союзника «залипал» на враге.** `hideCombatHealthBars()` сбрасывал `mAlly = false`,
не возвращая скин виджета в красный. Следующий враг, попавший в этот слот, проходил проверку
`state.mAlly != candidate.mAlly` как «изменений нет» и получал **зелёную** полосу.
Добавлено отдельное поле `mSkinAlly` — реально надетый скин, отдельно от флага союзника.

**2. Полоски за краем экрана не скрывались.** `RenderingManager::getScreenBounds` инициализирует
экстенты как `min = 1, max = 0`, поэтому у полностью ушедшего за кадр актёра результат
приходит прижатым к границе, а не признаком «невидим». Условие `maxX >= 0 && minX <= 1 && ...`
было тождественно истинным. Заменено на строгие сравнения, и в HUD полоска теперь скрывается,
когда её якорь вышел за экран, вместо прижатия к краю (`std::max(2, std::min(...))` убран).

**3. Отсечение «за камерой» могло не работать от первого лица.** Проверка строилась на
`focal - camera` из `Camera::getPosition`, а в первом лице фокус и камера совпадают → нулевой
вектор → `forward.length2() <= 0.000001` → **false для каждого актёра**, то есть полосок нет
вовсе. Добавлен запасной путь: направление берётся из ориентации игрока (в первом лице она и
есть направление камеры), позиция глаза — из `getCameraPosition()`.

**4. Бой через границу ячейки терял полоску.** `actor.getCell() != player.getCell()` отсекал
преследователя, перешедшего в соседнюю экстерьерную ячейку. Введён `sharesCombatSpace()`:
одна ячейка либо обе экстерьерные.

**5. Полоски менялись местами между актёрами.** Слоты заполнялись заново по дистанции, поэтому
при обгоне два участника обменивались виджетами — вместе с цветом и с состоянием ProgressBar.
Распределение сделано стабильным: актёр остаётся на своём виджете, освободившиеся слоты
получают новых участников.

**6. Падение при отсутствующей настройке.** `Settings::Manager::getString` бросает исключение
для ключа, которого нет в `settings-default.cfg`, а `getNpcBarMode()` вызывается каждый кадр.
Обёрнуто в `try/catch` с запасным режимом `both`.

## Проверить на своей стороне

- **`settings-default.cfg`**: в архиве его нет, а код читает `[HUD] npc bar mode` и
  `[GUI] target info panel`. Если этих ключей в файле нет — до правки №6 это был бы креш HUD
  на первом же кадре. Убедись, что ключи заведены.
- **Скин `MW_Progress_Green`** должен существовать в `files/mygui/openmw_progress.skin.xml`
  (в архиве этого файла нет). `changeWidgetSkin` на несуществующем скине бросит исключение.
- **LOS проверяется на скане (10 Гц)**, а не каждый кадр — за препятствием полоска гаснет с
  задержкой до 100 мс. Это следствие заявленной схемы «список пересчитывается 10 раз в секунду»;
  если нужно строже, LOS придётся вынести в покадровый цикл (24 луча на кадр).
- **Режимы GUI**: скрывается только `GM_Dialogue`. В инвентаре/карте полоски продолжат
  рисоваться поверх мира. Если это нежелательно — добавь проверку `isGuiMode()`.
- Существо, воюющее с твоим спутником, но не с тобой, полоски не получает (по правилу
  «в AiCombat с игроком») и показывает обычную hover-панель.
